# 牵衣 Qianyi

牵衣是一个用于服装设计与布料模拟的 Blender 插件。它给版师提供 2D 版片窗口、
缝线编辑器、参数化版片库，以及在人体上实时跑起来的布料模拟，物理部分由 CUDA
引擎计算。

本文件是 [README.md](README.md) 的中文版。

## 一次发布同时包含两个仓库

| 部分 | 是什么 | 位置 |
| --- | --- | --- |
| **Qianyi**（本仓库） | Blender 插件，要求 Blender 4.3+，GPL-3.0-or-later | <https://github.com/PDE26jjk/Qianyi> |
| **Qianyi_DP** | 模拟与几何引擎：C++20 + CUDA + pybind11，编译成 Blender 能导入的 Python 扩展模块 | <https://github.com/PDE26jjk/Qianyi_DP> |

插件本身不能模拟：它负责组装网格与缝线数据，求解由引擎完成。所以发布时两个仓库
一起发，并固定"哪个插件版本对应哪个引擎构建"。

## 运行要求

- Blender 4.3 或更高版本。
- 英伟达（NVIDIA）显卡与可用的 CUDA 驱动。引擎是 CUDA 程序，运行的不只是模拟：
  版片网格生成（点采样与三角剖分）、轮廓自交检测、缝线辅助计算也都在引擎里，
  因此没有 CUDA 设备的机器无法完成这些工作。
- `Qianyi_DP` 模块必须与本机 Blender 的 Python ABI 匹配，并且能被 Blender 的
  Python 解释器导入。
- 不引入第三方 Python 包：只使用 Blender 自带的内容（含 numpy）。

## 目前已经可用的部分

- **工程**就是 Blender 的节点树，一个 `.blend` 可以放多个工程，每个工程有自己
  的版片、缝线和面料。
- **版片**：笔绘创建，边可以是直线、三次 Bezier 或插值样条；版片可带内部线
  （开放线、闭合环、挖洞），内部线与轮廓求交后会切开 section 并标记外部分。
- **版片库**：26 个内置参数化构件（矩形、带缺口版片、百褶版片、腰头，以及
  GarmentCode 的成套服装构件），并支持用户构件目录热重载。
- **缝线**：把一块版片的一段边与另一块版片的一段边缝起来，可跨多条连续边，
  方向由点击位置决定，可上色。
- **模拟**：选择求解器、编辑完整参数块（含未知键）、自由模拟或跟随动画时间线、
  录制与回放帧缓存、把缓存导出为 PC2（Mesh Cache 修改器）。
- **脚本接口**（`qyapi`）：用一条普通 Python 语句完成上面所有事情，每次写入
  对应一步撤销。

## 路线图

下面按类别列出本插件距离一个生产级服装设计工具还差什么。`[x]` 表示已实现，
`[ ]` 表示未实现。带变更名的条目在 `openspec/changes/<名字>/` 里有完整规格。

### 1. 版片状态与物理行为

- [x] 障碍物对象参与模拟，可设碰撞层，可按帧更新顶点。
- [ ] 版片级状态：参与解算 / 不解算 / 冻结 / 硬化（塑化）——
  `pattern-states-and-display`。
- [ ] 版片级刚度倍率，覆盖共享面料的数值 —— `pattern-states-and-display`。
- [ ] 把当前褶皱烘焙进静止形状（塑化冻结）：引擎侧是 Qianyi_DP 的
  `cloth-plasticity` 变更，引擎落地后前端加按钮。
- [ ] 真正的刚体版片（而不是刚度倍率）。
- [ ] Bond 粘合：两块版片直接粘成一体、不走缝线（热熔胶、无缝工艺）。
- [ ] Skive 削薄：厚度沿边渐变（皮革、鞋面、厚料）。

### 2. 显示与视口

- [x] 版片窗口绘制：轮廓、内部线、样条点、缝线、预选高亮、纱向、轮廓自交标记。
- [x] 版片窗口显示模式：纯色、线框、网格、受力、debug ——
  `pattern-states-and-display`。
- [x] 3D 视口的受力与 debug 顶点着色，以覆盖层绘制在 Blender 自身渲染之上
  —— `pattern-states-and-display`。
- [x] 3D 视口按缝合顶点对绘制缝线，带深度 —— `pattern-states-and-display`。
- [x] 人体剪影投影到版片窗口，作为对齐参考（按工程指定集合，1:1 投影并可叠加网格，
  带缓存）—— `pattern-states-and-display`。
- [ ] 点与线的抗锯齿，以及重绘后仍生效的线宽控制。
- [ ] 面料贴图与 UV 显示。

### 3. 版片几何工具

- [x] 笔绘创建、插入顶点或样条点、移动、旋转、缩放、框选、删除。
- [x] 参数化矩形（`square` 构件）、带缺口版片、百褶版片、腰头；参数变化时原地
  重建并重映射缝线。
- [ ] 把一条边或一串边按弧长平均分成 N 段，或按指定长度与切分次数分段 ——
  `pattern-editing-toolkit`。
- [ ] 导角：圆角、直线倒角、凹圆角一个点变两点 —— `pattern-editing-toolkit`。
- [ ] 延展：以轴点旋转半个版片并补出张开的扇形 ——
  `pattern-editing-toolkit`。
- [x] 拖动曲线成形：抓住边上任意一点拖，曲线跟着鼠标走、两端不动。直线与贝塞尔
  只改两个手柄，样条只改已有的控制点；沿线拖动仍是直线。
- [ ] 通用圆与圆环生成器 —— `pattern-editing-toolkit`。
- [ ] 版片元素的复制与粘贴。
- [ ] 测量工具：点、边与人体之间的距离和夹角。

### 4. 内部线

- [x] 绘制、删除、改形内部线，支持闭合环挖洞，与轮廓求交并标记外部分。
- [ ] 沿内部线把版片切成两块 —— `pattern-editing-toolkit`。
- [ ] 把一串轮廓边转成内部线 —— `pattern-editing-toolkit`。
- [ ] 按带符号距离重复生成内部线，两端可裁剪、延伸到轮廓或保持原样 ——
  `pattern-editing-toolkit`。
- [ ] 内部线可作为缝线的一侧（省道缝合）—— `pattern-editing-toolkit`。

### 5. 褶皱与服装专用指令

- [x] 参数化百褶版片构件（顶边折成锯齿）。
- [ ] 翻折褶皱：在已有版片上按标记线做刀褶/箱褶 —— 等引擎侧支持内部线角度。
- [ ] 缝制褶皱：连缝线一起生成，把褶固定住 —— 同样等引擎侧支持。
- [ ] 抽褶与荷叶边：长边缝到短边并让料堆起来。
- [ ] 省道一键成型（标记、折叠、缝合）。

### 6. 缝线

- [x] 1:1 缝线，两端位置自由、可跨多条连续边，可上色，方向由点击决定。
- [x] 构件自带缝线，版片重建时按边标签与几何重映射。
- [x] 自由绘制缝线：按住沿轮廓拖出第一半（起点吸附顶点与已有半边端点），
  画第二半时吸附"与第一半等长"的位置并在预览里标出。
- [x] 半边编辑：拖端点增长/缩短（吸附顶点、其它半边端点、对侧半边的等长点），
  拖半边体则两端一起沿轮廓平移、各自吸附；一次拖动一步撤销。
- [x] 两个半边无法配对（一条缝线的走查嵌在另一条里）时，把涉及的缝线标红、
  其版片不生成 mesh 且禁止开始模拟，修好后自动恢复。
- [ ] 多对多缝线：每侧是一组按绘制顺序与方向的半边，按长度比例对 section
  匹配 —— `pattern-editing-toolkit`。
- [ ] 每条缝线自己的缝合参数（强度、针数），而不是全场景一个缝合刚度。
- [ ] 直缝以外的缝合类型：贴条、包边、折边。

### 7. 版片、复制与实例

- [x] 实例复制（联动编辑）与镜像复制。
- [ ] 原地翻转（水平、垂直、沿两点连线）—— `pattern-editing-toolkit`。
- [ ] 复制时选择是否带内部线 —— `pattern-editing-toolkit`。
- [ ] 复制选中范围内的缝线（双层裁片）—— `pattern-editing-toolkit`。
- [ ] 围绕工程轴（而不是版片自身锚点）镜像一块版片或一组版片。
- [ ] 分组：命名的一组版片一起移动、一起隐藏。

### 8. 模拟控制与环境

- [x] 求解器选择（PDNewton，以及实验性的 VBD / XPBD / Explicit）、完整参数块、
  自定义键值参数、参数 JSON 导入、"启动时应用"开关。
- [x] 自由模拟、跟随动画时间线模拟、帧缓存录制与回放、PC2 导出（Mesh Cache
  修改器）。
- [x] 重力、地面接触、碰撞层、3D 视口的拾取拖动。
- [x] 视口内的模拟 HUD：运行状态、求解器与帧数，以及实时速度（模拟时间/墙钟时间）。
- [ ] 风与空气力（需要引擎支持）。
- [ ] 压力/充气（羽绒服这类填充服装，需要引擎支持）。
- [ ] 人体管理：可复用的模特列表、按服装绑定人体、可撤销的换人。
- [ ] 尺寸驱动：把人体尺寸作为生成器参数的来源（目前所有参数都要手工给数值）。

### 9. 网格与拓扑

- [x] 版片网格按 granularity 从边界采样，经引擎的约束三角剖分生成。
- [ ] 四边形（或四边形为主）版片网格，需要引擎支持。
- [ ] UI 里的网格密度控制：缝线附近更密、版片内部更疏。

### 10. 读写与互操作

- [x] 全部数据存在 `.blend` 里，支持撤销/重做。
- [x] Marvelous Designer 工程导入（`.zpac`）。
- [x] 场景快照（`scene.json` + `scene.npz`），可在 Blender 之外复现场景。
- [ ] 版片与缝线导出为通用格式（OBJ、DXF、AAMA/ASTM、glTF 或 FBX），
  使纸样可以带到别的软件。
- [ ] 面料库与版片库的导入导出（共享素材库，而不是每个工程各一份）。
- [ ] 有文档的"快照 → 重放 → 对比"闭环。

### 11. 脚本与自动化

- [x] `qyapi`：工程、版片、缝线、生成器、模拟，含 `help()`、`state()`、事务，
  每次写入一步撤销（见 `docs/agent-api.md`）。
- [x] 构件 API 可以脱离场景直接构建版片，便于先写构件再放进工程。
- [ ] 用于回归的"快照/重放对比"报告。
- [ ] 可选：在 `qyapi` 之上加一层 MCP，供外部 Agent 调用。

### 12. 质量、测试与文档

- [x] 版片库的纯 CPU 单元测试（`python Qianyi/patternlib/tests/run_tests.py`，
  只依赖 numpy，不需要 Blender）。
- [x] 轮廓自交检测，以及记录在 OpenSpec 变更里的缝线方向与相交探针。
- [ ] 新命令与显示模式的回归测试，随功能一起落地。
- [ ] 发布检查表：每版插件对应哪个引擎构建、发布前验证哪些内容。
- [ ] 清理遗留占位：工具设置里仍是 `?????` 的文案、枚举里两个未实现的 TODO

## 开发

- 版片库测试（不需要 Blender，也不需要引擎）：

  ```bash
  python Qianyi/patternlib/tests/run_tests.py
  ```

- 设计工作用 OpenSpec 跟踪：

  ```bash
  openspec list
  openspec status --change pattern-states-and-display
  openspec validate pattern-states-and-display --strict
  ```

- 约定：代码注释与需要归档的公开文件用英文；数值计算用 numpy 向量化而不是
  Python 循环；不引入第三方 Python 依赖；本机路径与本地构建产物不出现在提交
  的文件里。
